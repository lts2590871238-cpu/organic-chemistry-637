# 南京工业大学637有机化学 · 21天刷题站

独立React/TypeScript/Vite静态工程；母版取自物化802，原目录未修改。当前为2026-10-24网站工程封存版，可部署GitHub Pages。交付范围、内容状态和已知边界见《封存交付说明.md》。

## 使用

双击 `启动网站.cmd`，在浏览器打开 http://localhost:3000/ 。该脚本仅使用本机已有Python运行时提供docs静态服务，不依赖研究工作区运行。服务在后台运行；重复双击会复用本网站服务，不再创建冲突的监听端口。

本机可双击 `构建网站.cmd`，使用既有运行工具更新docs，无需重新下载依赖。开发环境安装Node后：`npm ci`、`npm run dev`。构建：`npm run build`（输出docs）。检查：`npm run lint`、`npm run check`。本机已有依赖，可直接使用已有pnpm。
